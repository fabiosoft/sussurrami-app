# Sussurrami

Private, on-device dictation and meeting notes for macOS.

## Download

Get the latest version from [Releases](https://github.com/fabiosoft/sussurrami-app/releases/latest): download `Sussurrami_vX.Y.Z-N.zip`, unzip it and move **Sussurrami.app** to the Applications folder.

The app is signed with Developer ID and notarized by Apple. It updates itself: new versions are announced from the menu bar icon.

Requires macOS 14 or later.

---

This repository only hosts the public builds and the update feed (`appcast.xml` on the `gh-pages` branch).
